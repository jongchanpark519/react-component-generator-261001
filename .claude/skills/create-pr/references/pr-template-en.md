# English PR Template

> For overseas / English-language open source projects. Keep the section titles and order; write "N/A" for sections that don't apply.
> Text in `<...>` is a placeholder and must not remain in the final body.

## Body

```markdown
## Summary

<What this PR does in 1-3 sentences, including why it is needed.>

## Changes

- <Key change 1>
- <Key change 2>

## Type of change

- [ ] Feature (feat)
- [ ] Bug fix (fix)
- [ ] Refactor (refactor)
- [ ] Config / docs / other (chore)

## Related issues

<Closes #number / N/A>

## How to test

<Steps for the reviewer, or the commands you ran and their results. Write "Not run" if you did not run them.>

## Screenshots

<Before/after images for UI changes. N/A>

## Notes for reviewers

<Where to focus, known limitations, follow-ups. N/A>
```

## Title examples

- `Add 500-character prompt validation`
- `Fix server returning 500 on empty generation request`
