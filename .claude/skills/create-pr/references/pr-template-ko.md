# 한국어 PR 템플릿

> 한국 프로젝트용. 섹션 제목과 순서를 유지하고, 해당 없는 항목은 "해당 없음"으로 둔다.
> 아래 `<...>`는 채울 자리 표시이며 최종 본문에는 남기지 않는다.

## 본문

```markdown
## 개요

<이 PR이 무엇을 하는지 1~3문장. "왜" 필요한지를 포함한다.>

## 변경 사항

- <핵심 변경 1>
- <핵심 변경 2>

## 변경 유형

- [ ] 기능 추가 (feat)
- [ ] 버그 수정 (fix)
- [ ] 리팩터링 (refactor)
- [ ] 설정·문서 등 기타 (chore)

## 관련 이슈

<Closes #번호 / 해당 없음>

## 테스트 방법

<리뷰어가 직접 확인하는 절차 또는 실행한 명령과 결과. 실행하지 않았다면 "미실행"이라고 쓴다.>

## 스크린샷

<UI 변경 시 전/후 이미지. 해당 없음>

## 리뷰어 참고 사항

<중점적으로 봐야 할 부분, 알려진 한계, 후속 작업. 해당 없음>
```

## 제목 예시

- `feat: 프롬프트 500자 제한 검증 추가`
- `fix: 빈 입력 요청 시 서버가 500을 반환하던 문제 수정`
